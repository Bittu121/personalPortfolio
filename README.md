## Running Locally

Requires Node.js 16+ and npm.

```bash
git clone https://github.com/Bittu121/personalPortfolio.git
cd personalPortfolio
npm install
npm run dev
```

Runs at `http://localhost:3000`. Use `npm run build` for a production build.
